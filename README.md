# fred-login

Godkännandesida för Fred-API (Supabase OAuth 2.1), publicerad med GitHub Pages.
Innehåller ingen data – bara projektets publika URL och publika nyckel. Datan skyddas av RLS i Supabase.

Supabase-inställning: Site URL `https://gustav-collab.github.io/fred-login`, Authorization path `/consent.html`.
